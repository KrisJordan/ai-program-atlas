# Reproducible educational CSRankings integration

On October 11, 2026, the project owner confirmed: “We have permission to use csrankings data for this educational project.” This is the permission relied on for this Atlas integration. No separate licensor document was supplied and no broader permission is inferred. The official `gh-pages` commit endpoint identified snapshot `5e8a27d68310c728a182b8bb3b6437c39bce0cad`, dated September 28, 2026 at 04:21:02 UTC. Official raw GitHub responses were captured October 11, 2026. Exact original URLs, SHA256 hashes, byte lengths and content locators appear in `data/csrankings-crosswalk.json` and the computed artifact's methodology. The ignored `.cache/csrankings` holds complete original captures; none is committed. The Python scorer is an original implementation of inspected scoring rules rather than a copy of upstream implementation.

The project selects completed years **2016–2025 inclusive** and the upstream `countryabbrv=us` institution registry. Five field selections and their aggregate use AAAI/IJCAI (`ai`), CVPR/ECCV/ICCV (`vision`), ICLR/ICML/NeurIPS (`mlmining`, upstream venue key `nips`), ACL/EMNLP/NAACL (`nlp`), and SIGIR/WWW (`inforet`). KDD is marked a next-tier venue, disabled by default, and is excluded. Robotics is a different field. The site's date-dependent current default includes 2016–2026 on the capture date; our completed-year window is an explicit project choice.

For each complete US institution and selection, sum the upstream `adjustedcount` values in CSV order for the selected venue/year rows. These are author-adjusted fractional publication credits, already stored at upstream precision. We do not substitute paper counts, divide by faculty size or reconstruct unrounded fractions. A single field's score is its adjusted count plus one. The aggregate is the geometric mean of the five component counts plus one, without subtracting one afterward. An observed aggregate uses zero for an absent component only in the smoothing formula.

`value` is the upstream display score: round a positive score to one decimal with JavaScript's half-up behavior before sorting. Equal displayed values share competition ranks (1, 1, 3), rather than dense ranks or an average of ordinal field ranks. `unrounded_score` and the individual `adjusted_count` retain the underlying measures. Aggregate `adjusted_count` is null; `component_counts` supplies the five underlying sums. The entire upstream US population is ranked before the Atlas roster is joined.

The registry contains **201 US institutions**. Positive-output ranking populations are AI 171, vision 157, machine learning/data mining 165, NLP 151, information retrieval 136, aggregate 181. The complete artifact contains 1206 institution-selection rows, including 245 explicit listed/no-selected-output rows. The 194-institution Atlas roster has 91 explicit identity matches and 103 absent registry entries. Every unmatched or nonobserved measure/rank is null. Absence from this complete upstream registry is reported as `not_listed`, without inferring CS PhD ineligibility. The importer separately supports `outside_eligible`, `unmatched` and `source_missing` when evidence warrants them.

The maintained crosswalk contains explicit institution IDs and actual upstream labels; runtime matching never uses fuzzy names. Its department homepage provides the identity locator for renamed or campus-qualified labels. Rutgers Newark/Camden do not inherit New Brunswick's metrics; undergraduate military academies do not inherit the separately listed graduate military institutions; Claremont McKenna does not inherit Claremont Graduate University's metrics. Independent source review checks the campus aliases before acceptance. Michigan Ann Arbor has a bounded identity limitation: the registry links its CSE department and separately lists Dearborn and Flint, while the official indexed department address identifies Ann Arbor. Actual CSE and report bodies returned 403 and were not retried. The coordinator accepted that corroboration for institutional identity only; it supplies no curriculum evidence.

Rebuild using `.venv/bin/python scripts/import_csrankings.py --source-dir .cache/csrankings`; use `--download` to retrieve the exact pinned official raw GitHub inputs when network access is permitted. Downloads use bounded time/size, reject redirects and non-success responses, and verify hashes before storing raw files. Every rebuild verifies all pinned source hashes and the complete explicit roster mapping. The computed output records source, roster and crosswalk hashes and is deterministic for identical inputs. A new upstream snapshot requires a deliberate new provenance and identity review rather than silently refreshing live counts.

Focused tests cover author fractions, venue/year/country boundaries, zero-component aggregate smoothing, display rounding before tied ranking, full-population rank preservation, distinct null missingness, crosswalk coverage/campus duplication rejection and source-hash guards. Independent acceptance uses the actual pinned upstream JavaScript executed in an isolated VM, not these tests or a second copied formula. All 961 observed display scores and competition ranks matched that upstream execution; raw summation differences were below relative 1e-12 and did not change display scores or ranks. The independent peer report pins final artifact and crosswalk hashes.

This remains a snapshot publication indicator for research faculty eligible to advise CS PhDs. It does not measure undergraduate teaching quality, AI curriculum strength or faculty-size-normalized productivity. Affiliations reflect the pinned faculty snapshot rather than each paper's historical affiliation.
