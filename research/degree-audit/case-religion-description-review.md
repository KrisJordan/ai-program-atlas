Sources are the 2026–2027 Bulletin course-description pages at https://bulletin.case.edu/course-descriptions/rlgn/, https://bulletin.case.edu/course-descriptions/anee/, https://bulletin.case.edu/course-descriptions/ling/ and https://bulletin.case.edu/course-descriptions/jwst/ (permitted HTTP 200 captures). Raw text and documents remain outside public commits.

LING 333 instead teaches applied language pedagogy, including lesson design, instructional methods and material evaluation, so its domain-practice category is applications. Several descriptions name cross-list aliases, but this file does not change course identity groups or requirement roles.
